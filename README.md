# Дикий захід × Марія Василенко — мапа робіт

Односторінковий сайт з інтерактивною мапою вуличних робіт Марії Василенко (Золоті Ворота · Поділ).
Під кожною роботою висить QR-код. Він відкриває сторінку саме цієї роботи, а під нею мапу з іншими роботами.

> Зараз це **тестова версія**: мапа схематична (вулиці намальовані приблизно), тексти й точки робіт тестові.

## Що де лежить

| Файл / папка | Що це |
|---|---|
| `index.html` | Сам сайт: вигляд, мапа, перемикач мови UA/EN |
| `data/works.js` | **Список робіт**: назви, описи, де стоїть кружечок на мапі, висить чи зникла |
| `assets/map.jpg` | Картинка мапи |
| `assets/works/` | Мініатюри робіт (WebP з прозорим фоном) |
| `tools/gen_map.py` | Скрипт, який малює мапу в стилі Марії (Python) |
| `.nojekyll` | Службовий файл для GitHub Pages, не видаляти |

## Як додати або змінити роботу

1. Поклади картинку роботи в `assets/works/` (краще `.webp` або `.png`, до ~100 КБ).
2. Відкрий `data/works.js`:
   - додай шлях до картинки в список `IMG`;
   - додай рядок у список `W`, наприклад:
     ```js
     {id:12,x:40.5,y:60.2,t:{uk:"Назва",en:"Title"},d:{uk:"Опис",en:"Description"},ok:true,img:5},
     ```
   - `x`, `y` — положення на мапі у відсотках (0,0 — лівий верхній кут картинки мапи);
   - `ok:false` — робота зникла (буде пунктирний кружок).
3. Збережи. Сайт оновиться сам за 1–2 хвилини.

## QR-коди

Кожен QR веде на адресу сайту з номером роботи в кінці:

```
https://<адреса-сайту>/#w1
https://<адреса-сайту>/#w2
...
```

Номер після `#w` — це `id` роботи з `data/works.js`.
Важливо: **id роботи не змінювати після друку QR**, інакше код вестиме не туди.

## Публікація (GitHub Pages)

Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
За 1–2 хвилини сайт буде доступний за адресою `https://<акаунт>.github.io/<назва-репозиторію>/`.
Свій домен можна підключити пізніше там же (поле Custom domain).

## Як перемалювати мапу

Потрібен Python 3 з бібліотеками `numpy`, `opencv-python`, `pillow`:

```
pip install numpy opencv-python pillow
cd tools
python gen_map.py
```

Скрипт збереже нову мапу; її треба покласти замість `assets/map.jpg`.
Якщо змінити розмір мапи, поміняй також `IW` і `IH` в `index.html`.
